Политика конфиденциальности

Censeo Studio использует YouTube API Services для редакционной работы с одним каналом. На обработку данных со стороны Google распространяется политика конфиденциальности Google.

Какие данные используются

Панель получает идентификатор и название канала, идентификаторы роликов, сведения об обработке, видимости и времени публикации. При проверке комментариев панель получает их текст, идентификаторы, имя автора и дату. В журнале сохраняются статусы выпуска и действий с комментариями. Сведения из редакционного пакета отправляются на YouTube после подтверждения владельца.

Хранение и обработка

Закрытая панель хранит рабочие записи в OpenAI Sites. Владелец и уполномоченные им исполнители используют эти данные для выпуска видео и сопровождения канала. Для подготовки ответов нужный текст комментария может быть передан исполнителю в ChatGPT Work. Токен OAuth хранится как секрет на стороне сервера. Страница на GitHub Pages содержит только сведения о приложении.

Управление доступом и данными

Владелец может отключить доступ Censeo Studio в настройках безопасности Google. Для вопросов и запросов на удаление записей панели используйте контакт поддержки приложения, который указан на экране согласия Google. В запросе укажите ссылку на запись или ролик. Управление оригиналами роликов и комментариев на YouTube выполняется через YouTube.

Censeo Studio Privacy Policy

Censeo Studio is the private editorial application for the Censeo Studio YouTube channel. It uses YouTube API Services. See the Google Privacy Policy for information about Google's processing of data.

Data access

The channel owner authorizes access through Google OAuth. The application reads the authorized channel ID and title, video IDs, video processing and visibility status, scheduled and actual release times, and comment IDs, public author names, publication times and comment text on channel videos. The OAuth refresh token and client credentials are held as server-side secrets.

Data use

Channel and video data are used to check that actions target the intended channel and to reconcile scheduling, video processing and publication. The application sends owner-approved video packages and their metadata to YouTube for upload and scheduling. Comment data are used to match existing comments, prepare replies and carry out comment actions authorized by the channel owner.

Storage and sharing

OpenAI Sites hosts the private application and its operational records. Authorized editorial staff and the scheduled ChatGPT Work task can receive the comment text needed to review a comment and prepare a response for this channel. The application sends the resulting publication and comment actions to YouTube. The public informational site on GitHub Pages contains descriptions of the application and policies.

Retention, access revocation and deletion requests

Operational records are kept for reconciliation and review. The channel owner can revoke YouTube authorization in Google account security settings. To ask about data handling or request removal of a copy held by Censeo Studio, contact the developer at the support address shown on the Censeo Studio Google consent screen and identify the relevant video or comment. Removing the application copy and managing the original on YouTube are separate actions. Use YouTube Studio or YouTube to manage the original.

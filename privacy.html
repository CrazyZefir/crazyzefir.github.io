Политика конфиденциальности

Censeo Studio использует YouTube API Services для редакционной работы с одним каналом. На обработку данных со стороны Google распространяется политика конфиденциальности Google.

Какие данные используются

Панель получает идентификатор и название канала, идентификаторы роликов, сведения об обработке, видимости и времени публикации. При проверке комментариев панель получает их текст, идентификаторы, имя автора и дату. В журнале сохраняются статусы выпуска и действий с комментариями. Сведения из редакционного пакета отправляются на YouTube после подтверждения владельца.

Хранение и обработка

Закрытая панель хранит рабочие записи в OpenAI Sites. Владелец и уполномоченные им исполнители используют эти данные для выпуска видео и сопровождения канала. Для подготовки ответов нужный текст комментария может быть передан исполнителю в ChatGPT Work. Токен OAuth хранится как секрет на стороне сервера. Страница на GitHub Pages содержит только сведения о приложении.

Управление доступом и данными

Владелец может отключить доступ Censeo Studio в настройках безопасности Google. Для вопросов и запросов на удаление записей панели используйте контакт поддержки приложения, который указан на экране согласия Google. В запросе укажите ссылку на запись или ролик. Управление оригиналами роликов и комментариев на YouTube выполняется через YouTube.
